KEY FILES EXPLAINED:
================================================================================

manifest.json
  - Defines app name, colors, icons, and shortcuts
  - Tells browser how to display your app
  - Customize colors: Change theme_color to your brand color

service-worker.js
  - Enables offline functionality
  - Caches static assets (CSS, JS, images)
  - Network-first for PHP pages (always try online first)
  - Cache-first for static assets (use cache if available)

include/pwa-meta.php
  - Add PWA meta tags to any page
  - Use: <?php include 'include/pwa-meta.php'; ?>

TROUBLESHOOTING:
================================================================================

Service Worker not registering?
  ✓ Check console for errors (F12)
  ✓ Verify service-worker.js is in root directory
  ✓ On production, ensure HTTPS is enabled

Cache not updating?
  ✓ Clear site data: DevTools → Storage → Clear site data
  ✓ Or increment CACHE_NAME version in service-worker.js

Offline pages showing errors?
  ✓ Visit page while online first to cache it
  ✓ Dynamic PHP pages are cached if visited while online

FAQ:
================================================================================

Q: Will Service Workers work on localhost?
A: Yes! Localhost is treated as secure for development.

Q: How much storage for caching?
A: Typically 50MB per site (varies by browser).

Q: What if I update the service worker?
A: Users get new version on next visit. Old cache is auto-deleted.

Q: Do I need to do anything else?
A: Just test it! Optional: Add include to header.php for all pages.

Q: Can I control what gets cached?
A: Yes! Edit STATIC_ASSETS array in service-worker.js.

Q: Will this work on my hosting provider?
A: Yes! PWA works on any PHP hosting that supports HTTPS.
